# Meridian Compass employee tour

Reserved local assets:

- `meridian-compass-60-second-tour.mp4`
- `meridian-compass-60-second-tour.vtt`

The intended employee story is: introduce Compass (0–10s); ask the Nairobi
travel question naturally (10–22s); explain that Compass checks approved
Meridian information and authorised work context (22–35s); show what applies,
the recorded situation, approver and next step (35–46s); demonstrate a
confirmation-gated mock next step without implying a real external action
(46–55s); close with “Less searching. More doing.” (55–60s).

The optional recording must never replace or simulate the live application.
